# mikedmor.github.io

My project portfolio, at [mikedmor.github.io](https://mikedmor.github.io/). It fills itself in from
GitHub's public data on every visit: my profile, then a featured row, then every public repository
with search, a language filter and sorting. New projects show up on their own.

To change it, edit the settings at the top of the script in `index.html`:

- `FEATURED`: which projects go first, in order.
- `HIDE`: repositories to leave out.
- `NAMES`: how to write a project's name when its repository name isn't how you'd say it.

Project sites live in their own repositories, such as [Hearth](https://github.com/mikedmor/hearth)
at `/hearth/`. The `google….html` file proves to Google Search Console that this domain is mine;
keep it.
